# Indonesia Energy Security Monitor

Password-protected dashboard of the nested IRCGE model (world, ASEAN, Indonesia, islands, regions and 34 provinces solved in one equilibrium).

Prof. Yayan Satyakti, Universitas Padjadjaran. Model run: refined_v12 (17 October 2026; data to 17 October 2026).

The page is encrypted (AES-256-GCM, key derived from the password with PBKDF2-HMAC-SHA256); it opens only with the password. Licensed data (MOPS/Platts prices, Wood Mackenzie data) are not included.
